## 11. APPRENTISSAGES (ce que ce projet a appris)
- Sur le domaine : GDELT v2 API retourne du GeoJSON facilement consommable. ACLED nécessite des credentials mais offre des données de terrain beaucoup plus fiables que GDELT pour les conflits réels. La combinaison des deux donne une couverture media + terrain qui est puissante.
- Sur l'architecture Madgic : Le projet a été construit en autonomie totale (100% TypeScript/Next.js) sans aucun composant partagé Madgic. Le résultat est un produit fonctionnel (131 tests, 12 API, globe 3D) mais COMPLÈTEMENT déconnecté du reste de la plateforme. L'intégration des composants partagés (QuantumData, convolutions, design system) est le PRINCIPAL défi maintenant. **Le gap Python (shared core) vs TypeScript (Satellite-Spy) est un problème architectural non résolu.**
- Sur la collaboration : Le WorldModel ontology (17 entities, 14 relations) et l'EventBus pattern sont des contributions directement réutilisables par Quest XR et potentiellement par tous les projets. Le SSE simulation stream est prêt pour l'intégration Quest XR dès que leur ForceGraph3D est opérationnel.
